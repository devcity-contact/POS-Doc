API design

There are two APIs on one backend. The REST API (/api/v1) is for the admin web and online register lookups. The Sync API (/sync/v1) is for register pull and push. Both are described in one OpenAPI document, and the TypeScript clients are generated from it.

Conventions

TopicRule
StyleResource-oriented REST, JSON, camelCase fields, plural nouns: /api/v1/products/{id}. Actions that aren't CRUD use a verb sub-resource: POST /api/v1/cash-sessions/{id}/close.
VersioningMajor version in the path. Additive changes need no new version. Breaking changes need /v2, and both versions run until registers on N-1 are gone (INV-13).
Money and quantitiesStrings with 4 decimal places: "320.0000". Never JSON numbers (INV-03).
IDsUUIDv7 strings. Clients may supply the ID on create, which is required for register-created facts.
TimeISO-8601 UTC: 2026-11-19T04:12:09.120Z. Dates: 2026-11-19.
PaginationCursor-based: ?limit=50&cursor=…, and the response includes nextCursor. Offset pagination isn't allowed on large tables.
Filtering and sorting?branchId=…&from=2026-11-01&to=2026-11-30&sort=-completedAt
IdempotencyEvery POST that creates money or stock records accepts an Idempotency-Key header (UUID). The Sync API uses each item's ID instead.
ConcurrencyMutable resources return an ETag (version). PUT/PATCH require If-Match, and a mismatch returns 412.
LanguageAccept-Language: si localises error messages. Error codes never change.
Compressiongzip/br for responses over 1 KB. Registers send gzipped push bodies.

Error format

Errors use RFC 9457 Problem Details with a stable code (see the error code catalog).

HTTP/1.1 403 Forbidden
Content-Type: application/problem+json

{
  "type": "urn:retailos:error:AUTH-003",
  "title": "Permission denied",
  "status": 403,
  "code": "AUTH-003",
  "detail": "Missing permission: refund.create.above_limit",
  "instance": "/api/v1/returns",
  "requestId": "01J9Z…",
  "errors": []               // field errors for VAL-001: [{ "field": "lines[0].qty", "code": "MIN", "message": "…" }]
}

Never put stack traces, SQL, or another tenant's identifiers in an error body.

Rate limits

Endpoint groupLimitKey
Login, PIN, enroll, refresh10 per minute, then exponential lockoutIP + account / device

Exceeding a limit returns 429 with Retry-After. The proxy also applies coarse per-IP limits.

OpenAPI and client generation

  • springdoc generates /v3/api-docs, and CI saves it as backend/openapi.json. A diff check fails the build on breaking changes (openapi-diff).
  • packages/api-client is generated with openapi-typescript and openapi-fetch. Never hand-write request types.
  • Swagger UI is enabled in dev and staging only.
